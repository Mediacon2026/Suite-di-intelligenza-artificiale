# 13 - Security

## Principi
- Password cifrate.
- Autenticazione JWT.
- Ruoli e permessi granulari.
- Audit log modifiche.
- Backup periodici.
- Accesso documenti controllato.

## Dati sensibili
Il sistema tratta dati personali, documenti e pratiche. Devono essere previsti log, permessi e protezioni adeguate.
