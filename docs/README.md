---

# Visione

Mediacon Hub ERP è una piattaforma web progettata per centralizzare tutte le attività operative di Mediacon in un unico sistema.

L'obiettivo è eliminare la gestione frammentata tramite fogli Excel, documenti separati e archivi scollegati, creando un ambiente unico, sicuro e scalabile.
