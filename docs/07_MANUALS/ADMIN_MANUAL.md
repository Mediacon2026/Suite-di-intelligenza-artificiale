# Admin Manual

## Scopo
Manuale per amministratori di sistema, configuratori e responsabili tecnici di Mediacon Nexus ERP.

## Aree amministrative
- Configurazione organismi e sedi.
- Gestione utenti, ruoli e permessi.
- Parametri economici e regole di calcolo.
- Workflow, template e parser.
- Audit log, sicurezza e controlli.
- Migrazioni, ambienti e verifiche post release.

## Checklist amministrativa release
- Verificare versione applicativa e note di rilascio.
- Applicare eventuali migrazioni database.
- Controllare configurazioni obbligatorie.
- Verificare permessi dei ruoli impattati.
- Eseguire smoke test su dashboard, login, API principali e moduli rilasciati.

## Regola di manutenzione
Ogni nuova funzione amministrativa deve essere documentata prima del passaggio in produzione o in ambiente pilota.
