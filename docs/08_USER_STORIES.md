# 08 - User Stories

## Core
- Come Amministratore voglio creare utenti con ruoli diversi.
- Come Responsabile voglio gestire sedi e permessi.

## CRM
- Come Segreteria voglio creare un contatto unico.
- Come utente voglio vedere lo storico completo di un contatto.

## Mediazione
- Come Segreteria voglio aprire una mediazione.
- Come sistema voglio assegnare numero interno e DGStat.
- Come Responsabile voglio generare report trimestrali.
