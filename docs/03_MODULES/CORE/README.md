# CORE

Area documentale del Core Platform. Include Configuration Center, autenticazione, multi organismo, multi sede, ruoli, permessi, audit log e motori trasversali principali.

## Codici riferimento
Usare i codici `CORE-001` - `CORE-015` definiti in `docs/MODULE_INDEX.md`.

## Contenuti attesi
- Specifiche funzionali del core.
- Decisioni architetturali di piattaforma.
- Regole di configurazione e autorizzazione.
- Collegamenti a requisiti, API e test.
