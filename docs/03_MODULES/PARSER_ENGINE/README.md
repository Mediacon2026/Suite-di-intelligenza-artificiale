Area documentale del Parser Engine. Copre parser registry, parser verticali, advisor parser, classifier, OCR e confidence engine.

## Codici riferimento
Usare i codici `PARSER-001` - `PARSER-010` definiti in `docs/MODULE_INDEX.md`.

- Regole di classificazione e confidence.
- Integrazione con Document Engine e AI.
- Test su campioni, accuratezza e casi limite.
