# OCC

Area documentale del modulo OCC. Copre procedure, debitore, creditori, patrimonio, redditi, relazione, compensi, tribunale, scadenze e statistiche.

## Codici riferimento
Usare i codici `OCC-001` - `OCC-010` definiti in `docs/MODULE_INDEX.md`.

## Contenuti attesi
- Schede procedura e dati economico-patrimoniali.
- Relazioni, scadenze e interazioni con tribunale.
- Regole documentali e compensi.
- Test su flussi critici e consistenza dati.
