# MEDIAZIONE

Area documentale del modulo Mediazione. Copre procedimenti, parti, avvocati, mediatori, incontri, calendario, pagamenti, compensi, DGStat, verbali, accordi, PEC, firma digitale e archiviazione.

## Codici riferimento
Usare i codici `MED-001` - `MED-015` definiti in `docs/MODULE_INDEX.md`.

## Contenuti attesi
- Flussi operativi del procedimento.
- Regole economiche e documentali.
- Integrazioni con Case Engine, Document Engine e Workflow Engine.
- Test funzionali e regressioni di rilascio.
