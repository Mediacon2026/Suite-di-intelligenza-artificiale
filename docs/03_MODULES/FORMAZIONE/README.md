# FORMAZIONE

Area documentale del modulo Formazione. Copre corsi, docenti, calendario, aule, iscrizioni, presenze, quiz, attestati, pagamenti e statistiche.

## Codici riferimento
Usare i codici `TRAIN-001` - `TRAIN-010` definiti in `docs/MODULE_INDEX.md`.

## Contenuti attesi
- Requisiti dei corsi e delle iscrizioni.
- Gestione presenze, attestati e pagamenti.
- Reportistica e statistiche.
- Collegamento con CRM, documenti e workflow.
