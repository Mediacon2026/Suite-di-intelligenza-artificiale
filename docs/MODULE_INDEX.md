# Module Index

## Scopo
`MODULE_INDEX.md` e' il registro ufficiale dei codici modulo di Mediacon Nexus ERP. Ogni requisito, attivita', test, modifica di release e documento tecnico deve usare questi codici per garantire tracciabilita' industriale.

## Regole di utilizzo
- Non modificare un codice modulo gia' assegnato senza decisione di governance.
- Aggiungere nuovi codici solo quando il perimetro funzionale e' stabile.
- Collegare ogni release ai codici modulo impattati.
- Usare i codici nei ticket, nel test book, nel changelog e nelle note di rilascio.
