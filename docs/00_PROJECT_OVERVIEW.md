# 00 - Project Overview

Mediacon Hub ERP è il progetto software centrale per digitalizzare e coordinare le attività di Mediacon e delle aree professionali collegate.

## Visione
Un unico sistema per gestire contatti, pratiche, mediazioni, corsi, orientamento, OCC, crisi d'impresa, documenti, pagamenti, scadenze, report e AI Assistant.

## Principio guida
Il sistema nasce come piattaforma modulare: ogni area può essere attivata, configurata e sviluppata in modo progressivo.
