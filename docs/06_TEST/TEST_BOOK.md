# Test Book

## Scopo
Definire il registro dei test funzionali, tecnici e di regressione del progetto Mediacon Nexus ERP.

## Tipologie di test
- Smoke test: verifica avvio backend, frontend e database.
- API test: verifica contratti, errori e permessi.
- Functional test: verifica flussi utente per modulo.
- Regression test: verifica che una release non rompa funzioni gia' rilasciate.
- Data test: verifica migrazioni e consistenza dati.
- Security test: verifica ruoli, permessi, audit e separazione dati.

## Regola di release
Nessuna release deve essere considerata pronta senza test book aggiornato sui moduli impattati.
