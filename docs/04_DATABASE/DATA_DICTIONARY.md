# Data Dictionary

## Scopo
Il dizionario dati descrive tabelle, campi, relazioni e vincoli del database Mediacon Nexus ERP.

## Convenzione scheda tabella

```text
Tabella:
Modulo:
Descrizione:
Chiave primaria:
Relazioni:
Campi principali:
Note di sicurezza:
```

## Aree iniziali da censire
- Organizzazioni, sedi, utenti, ruoli e permessi.
- Contatti, CRM e lead.
- Fascicoli, documenti, timeline, task e scadenze.
- Mediazioni, tariffari, incontri, parti e pagamenti.
- Configurazioni, workflow, template, parser e regole economiche.

## Regola di manutenzione
Ogni migrazione che introduce o modifica dati persistenti deve aggiornare questo documento nella stessa release.
