# Components

Reusable components live in `template-parts/`:

- `breadcrumbs.php`
- `hero.php`
- `card.php`
- `cta.php`
- `faq.php`
- `timeline.php`
- `table.php`
- `form.php` (presentation wrapper only)
- `badge.php`
- `alert.php`
- `sidebar.php`
- `pagination.php`

The sticky header contains desktop and mobile navigation, optional mega menu,
search, and the two project CTAs. The footer exposes menu and widget locations
so verified institutional links, contacts, and social URLs remain managed as
WordPress content rather than hard-coded theme data.
