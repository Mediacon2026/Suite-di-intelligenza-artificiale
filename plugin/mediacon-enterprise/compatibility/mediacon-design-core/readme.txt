Ponte di compatibilità che soddisfa lo slug mediacon-design-core e delega esclusivamente a Mediacon Enterprise.

== Installation ==

1. Installare e attivare Mediacon Enterprise.
2. Verificare che il modulo Compatibility sia abilitato.
3. Installare questo archivio senza rinominare la cartella mediacon-design-core.
4. Attivare il bridge.

Il bridge non contiene un secondo Core e non scrive direttamente nella directory dei plugin.
